# Sistema de Gestão Edificar ACS Construtora

Este projeto foi desenvolvido como parte do **Projeto Integrado em Engenharia de Software**. O objetivo principal é automatizar e organizar o controle de obras e materiais da Edificar ACS, eliminando processos manuais e reduzindo falhas operacionais.

# Sobre o Projeto

O software permite o cadastro de obras e o gerenciamento de insumos, garantindo que cada entrada e saída de material seja validada por regras de negócio rígidas antes de ser processada. 

# Principais Funcionalidades:
**Gestão de Obras:** Registro detalhado de novas obras e seus endereços.
**Controle de Materiais:** Cadastro de materiais com validação de campos obrigatórios e quantidades.
**Rigor Técnico:** Bloqueio de entradas inválidas (ex: quantidades negativas ou campos vazios).


# Tecnologias e Metodologia

Para garantir a entrega e a qualidade, foram utilizadas:
  **Linguagem:** JavaScript (Node.js)
  **Framework de Testes:** [Jest]
  **Modelagem:** UML (Diagramas de Casos de Uso e Atividades)
  **Metodologia:** Ciclo de Vida Incremental


# Qualidade de Software e Testes

Um dos pilares deste projeto é a confiabilidade. O código foi submetido a testes unitários rigorosos para garantir que todos os requisitos funcionais fossem atendidos.

**Cobertura de Código** (Coverage): 100%
**Rastreabilidade:** Cada decisão nos diagramas de atividades possui um teste correspondente no código.

# Documentação e Diagramas

O projeto inclui documentação UML completa:
**Diagrama de Casos de Uso:** Define as permissões do administrador.
**Diagrama de Atividades:** Mapeia o fluxo lógico de cadastro de materiais e obras.
